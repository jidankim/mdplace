# Domain Docs

This is a single-context repository.

Before exploring, read the root `CONTEXT.md` and any relevant ADRs under `docs/adr/`. Proceed silently when optional domain files do not exist.

Use the glossary’s canonical vocabulary in issue titles, proposals, hypotheses, and tests. Do not use synonyms listed under `_Avoid_`.

If work contradicts an existing ADR, surface the conflict explicitly rather than silently overriding it.
